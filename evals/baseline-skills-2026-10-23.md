# Skill baseline 2026-10-23: every skill eval, run and graded with no human in the loop

- Commit: `library-hygiene` branch from main 0921902, with the skill-eval support in `evals/run.sh` and `evals/check.py` added by this PR.
- `evals/run.sh -s -j 5`: 10 skill evals, each in a fresh `claude -p` session (Claude Code 2.1.309). Each session loaded the skill its folder name names and answered `request.md` or `text.md`, with no Write or Edit tool and the keys, run files, and RESULTS.md off limits.
- `evals/check.py -j 5`: the judge alone, with the request, the key, and the answer inline. There is no mechanical check for skill evals.
- **Result: 6 of 10 pass.**

## The four failures

- **015-consult-events-carousel: the key is out of date.** Item 3 expects consult to find no carousel entry and say "no entry yet". `knowledge/patterns/carousel.md` and `knowledge/ux/carousels.md` have existed since the patterns and ux domains landed, and the answer used them, citing tier and source. Run 3 in `015-consult-events-carousel/run-2026-10-22-consult.md` already recorded the same change by hand. The key is Derek's; left for him to update. The rest of the answer met the key.
- **017-consult-registration-form: real gaps, small.** The answer chose checkboxes over a multi-select list box without weighing the two (item 5), and its screen-reader and zoom tests did not name the checkbox group (item 6).
- **019-at-test-protocol-modal-dialog: real gap.** The keyboard section tests Enter and Space on "Cancel" only, not on "Delete search" (item 3).
- **020-at-test-protocol-data-table: real must-not.** The JAWS step says "The light red background is not spoken", which predicts screen-reader output instead of leaving it to the tester, and a developer note says what keyboard users "get".

Earlier hand runs of 015 to 020 passed (`run-2026-10-22-*.md`), and those were prompt tests, not fresh sessions. A single headless run is not proof either way; the at-test-protocol and consult failures are worth a second run after any change to those skills.
