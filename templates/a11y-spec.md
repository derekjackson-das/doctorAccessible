# Accessibility spec: <project name>

One per project. Every Doctor Accessible mode reads this before acting and writes decisions back to it. Copy it to the root of the project as `a11y-spec.md`. Keep it current; a stale entry is worse than none.

## Conformance target

WCAG 2.2 Level AA, unless a regulation names another version. State which, and why, if so.

## Who we are building for

The people this project serves, in their own situations, including those using assistive technology. Then the assistive technology and browser pairs the team tests with, for example NVDA with Chrome, VoiceOver with Safari on macOS and iOS, JAWS with Chrome, keyboard only, 400% zoom, reduced motion, forced colors.
