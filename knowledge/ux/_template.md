# UX heuristic: Pattern name (or: UX need-finding: Topic)

Two shapes share this folder. Heuristic entries say when an interface pattern serves people. Need-finding entries say how to learn who a thing is for. Use the matching shape below and delete the other.

- Sources: author, "Title", publisher, date (and "last reviewed" date if the page shows one), URL. One line each.
- Tier: 3, practitioner and usability research; 2 for any W3C source cited. Nielsen Norman Group is on `knowledge/SOURCES.md` for UX claims only; it is not an accessibility authority. Accessibility claims come from the linked `wcag/` and `coga/` entries, not from these sources.
- Related entries: `coga/...`, `wcag/...`
- Verified against the live sources: YYYY-MM-DD by <name>

## Status and reporting

A finding that rests only on this entry is reported as likely or manual review, never definite. A WCAG failure in the same code is reported once, under its criterion. In consult, this entry supports a question or a recommendation; it does not decide for the developer.
